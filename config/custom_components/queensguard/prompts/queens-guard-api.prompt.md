Goal: Build a Home Assistant Integration that exposes an llm.API for Voice Assistants with RAG support for retrieving relevant home context. This will allow exposing more entities to the LLM as every entity won't be provided as context for every chat request.

Implementation Steps:
1. Create config_flow.py for configuring the integration. See [Config Flow Handler](https://developers.home-assistant.io/docs/config_entries_config_flow_handler/), for setting up a config flow. This is the config flow:
    - Step One: Setup chromadb and ollama connections, test that the connections are valid.
    - Step Two: After verifying the connections, list the available models and allow the user to select a downloaded embedding model to use.
        - If the model does not exist, allow download the model with ollama and wait for the download to complete, similar to the ollama integration config_flow.
2. in async_setup_entry, store the ollama and chromadb client instances in the config entry, similar to the ollama integration in #file:/workspaces/core/homeassistant/components/ollama/__init__.py .
3. Create an llm API Instance similar to HomeAssistants AssistAPI.
    - Expose the same tools as the Assist API
    - Replace the prompt generated by the assist API with context from chromadb
4. Create an embeddings manager in embeddings.py which sets up listeners so that each time the state of an entity exposed to voice assistants changes, we update the embeddings for that entity, area, or floor. The embeddings manager uses
5. Override the _async_get_api_prompt callback so that instead of returning all the exposed entities, we fetch relevant embeddings from chromadb instead.

General Guidance:
This integration only supports a single config entry.

Use the chromadb python package for chromadb. See [Client](https://docs.trychroma.com/reference/python/client) and [Collection](https://docs.trychroma.com/reference/python/collection). Do not use an http client.

Use the ollama python package for ollama. The implementation is in #file:/home/vscode/.local/ha-venv/lib/python3.13/site-packages/ollama/__init__.py . Do not use an http client.
